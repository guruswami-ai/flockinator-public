## Resume procedure

1. Choose one work package below and recheck current source and evidence against
   the linked issue. This is a dated snapshot, not a live deployment inventory.
2. Reopen its issue or create a focused successor linking the original and this
   document. Assign one accountable coordinator and identify disjoint files for
   workers before editing shared components.
3. Agree on acceptance criteria and dependencies. For experiments, review and
   freeze protocol, source/configuration, seed exposure and analysis before fresh
   collection. Preserve historical results and report null/adverse outcomes.
4. Obtain any required device/participant/data permissions separately. A merged
   proposal, successful host test or closed issue is not physical acceptance.
5. Update this ledger with the new issue, evidence and disposition when work
   resumes. Select work for useful evidence, not to increase experiment count.
